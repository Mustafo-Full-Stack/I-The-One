## 💻 ПРИМЕРЫ КОДА

### Простой пример - загрузить модель
```javascript
import { Player } from './js/game/PlayerNew.js'

const player = new Player(scene)

// Загрузить готовую модель
await player.loadModelFromURL('/models/minion-a01.glb')
```

### С управлением
```javascript
import { CharacterController } from './js/game/CharacterController.js'

const controller = new CharacterController(playerGroup)

// В игровом цикле
function animate() {
  controller.update(0.016) // deltaTime
  renderer.render(scene, camera)
}
```

### Несколько персонажей
```javascript
import { CharacterLoader } from './js/game/CharacterLoader.js'

const loader = new CharacterLoader(scene)

// Загрузить модели
await loader.loadCharacter('/models/minion-a01.glb', 'minion1')
await loader.loadCharacter('/models/minion-a02.glb', 'minion2')

// Переключаться
loader.switchCharacter('minion1')
```

## ✨ КЛЮЧЕВЫЕ ОСОБЕННОСТИ

### 1. Управление
- WASD или стрелки для движения
- SPACE для прыжка
- Персонаж поворачивается в сторону движения
- Камера следует за персонажем

### 2. Загрузка моделей
- Поддержка GLB и GLTF
- Загрузка с URL
- Локальная загрузка
- Fallback на встроенного персонажа

### 3. Анимации
- Автоматическое воспроизведение при загрузке
- Возможность переключаться между клипами
- Поддержка loop и one-shot анимаций

### 4. Оптимизация
- PCFSoftShadowMap для мягких теней
- Оптимизированное освещение
- Готовые модели оптимизированы для браузера
