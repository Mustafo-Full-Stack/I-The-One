# 3D Browser Game

Современная минималистичная 3D-игра для браузера на Three.js и Vite.

## 🎮 Запуск проекта

### Быстрый старт (рекомендуется):
Откройте файл **game.html** в браузере Chrome или любом другом современном браузере.

### УЖЕ РАБОТАЕТ В : https://i-the-one.vercel.app/

### С использованием Vite:
```bash
npm install
npm run dev
```

## 📁 Структура проекта

```
I'm-the0one/
├── game.html                  # Standalone версия (готовая к использованию)
├── index.html                 # Главный HTML файл для Vite
├── package.json               # Зависимости проекта
├── vite.config.js            # Конфигурация Vite
├── src/
│   ├── main.js               # Точка входа приложения
│   ├── styles/
│   │   └── main.css          # Стили интерфейса
│   └── js/
│       ├── MenuManager.js    # Управление меню
│       ├── GameManager.js    # Управление игрой
│       └── game/
│           ├── Scene.js      # 3D-сцена и арена
│           ├── Camera.js     # Камера
│           ├── Lighting.js   # Система освещения
│           └── Player.js     # Персонаж и анимация
```

## ✨ Возможности

### Главное меню:
- ✅ Современный минималистичный дизайн
- ✅ Тёмная цветовая палитра (графитовый, синий)
- ✅ Профессиональные кнопки с hover-эффектами
- ✅ Адаптивная вёрстка для мобильных устройств
- ✅ Плавные анимации и переходы

### Игровой мир:
- ✅ Профессиональная 3D-арена с бортиками
- ✅ Качественное направленное освещение
- ✅ Реалистичные мягкие тени (PCFSoftShadowMap)
- ✅ Гармоничная цветовая палитра
- ✅ Угловые столбы с акцентными элементами
- ✅ Двухуровневый пол арены (внешний + внутренний)
- ✅ Лёгкий туман для глубины сцены

### Персонаж:
- ✅ Геометрический персонаж из простых форм
- ✅ Гармоничные цвета (телесный, синий, серый)
- ✅ Плавная idle-анимация (покачивание)
- ✅ Тень под персонажем
- ✅ Реалистичные материалы с правильными параметрами

## 🎨 Визуальные изменения

### Меню:
- **Фон**: Изменён с яркого градиента на спокойный тёмно-синий (#0a0e27 → #1a1f3a)
- **Заголовок**: Убран неоновый градиент, добавлен простой белый текст (#e8edf5)
- **Кнопки**: Заменены яркие синие градиенты на матовые тёмно-синие (#2a3f5f)
- **Акцент**: Кнопка "Старт" выделена спокойным голубым (#4a7ba7)
- **Типографика**: Более профессиональный системный шрифт
- **Размеры**: Уменьшен размер заголовка с 4rem до 2.8rem

### Арена:
- **Удалены**: Высокие стены (15 единиц) и парящие неоновые кубы
- **Добавлены**: Низкие бортики (1.5 единицы) и угловые столбы
- **Фон**: Вместо градиента со звёздами — спокойный однотонный (#1a2332)
- **Туман**: Добавлен лёгкий туман для глубины
- **Пол**: Двухуровневый (внешний + внутренний игровой)
- **Цвета**: Серо-синие тона (#2d4059, #37475a, #1e2a38)

### Освещение:
- **Удалены**: Яркие цветные точечные светильники (голубой и розовый)
- **Добавлены**: Профессиональное направленное освещение
- **Тени**: Улучшены до PCFSoftShadowMap (мягкие реалистичные)
- **Интенсивность**: Снижена для более реалистичного вида

### Персонаж:
- **Цвета**: Изменены с ярких (оранжевый #ff9800, зелёный #4caf50) на спокойные (телесный #f5a57a, синий #4a7ba7, серый #37475a)
- **Пропорции**: Улучшены размеры головы, тела и конечностей
- **Анимация**: Более плавная и естественная idle-анимация
- **Тень**: Добавлена круглая тень под персонажем

### Камера:
- **FOV**: Изменён с 75° на 60° для более кинематографичного вида
- **Позиция**: Скорректирована для лучшего обзора арены
